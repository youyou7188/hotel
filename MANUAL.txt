================================================================================
【完全マニュアル】宿泊価格監視システム（スマホ対応 All-in-One Webアプリ版）
================================================================================

本システムは、出張や旅行の宿泊条件を登録しておくだけで、楽天トラベルとじゃらんの
公式空室検索APIを毎朝自動巡回し、最安プランや乗り換え推奨プランをスマホ画面で
直感的に確認できる自動監視システムです。

Googleスプレッドシートや別アプリへの移動は一切不要！
本Webアプリの画面1つだけで「登録」「検索」「確認」がすべて完結します。

1. このシステムでできること

================================================================================
1. このシステムでできること
================================================================================
(1) 予約済みホテルの乗り換えチェッカー
    - とりあえず仮予約（キープ）している金額（例: 12,000円）を登録しておくと、
      それより安いプランが出現した時に「🔥 乗り換えチャンス！ 最大 -¥2,500 安い！」
      と視覚的に特大ハイライトされます。
    - キャンセル料無料の期間中に、より安くて良い宿に乗り換えることができます。

(2) 未予約時の「最安TOP 5」ランキング
    - まだ宿を予約していない出張は、条件（禁煙・朝食・徒歩・星評価）に合致する
      おすすめ宿を安い順にベスト5をカード表示します。

(3) ワンタップで公式予約ページへ直行
    - 各ホテルカードの「楽天トラベルで予約」「じゃらんで予約」ボタンを押すだけで、
      そのまま公式のプラン予約ページへ一発でジャンプできます。

(4) 出張日程の「まとめ打ち」対応
    - 同じ行き先の出張なら、「10/15, 10/22, 11/05」とカンマで打つだけで
      複数回分の出張をまとめて一発登録できます。

(5) 毎朝8時（JST）の自動価格更新
    - GitHub Actionsが毎朝自動で最新の空室・価格をチェックし、Web画面を自動更新します。


================================================================================
2. 毎日の使い方（スマホで1タップ）
================================================================================
1. 発行されたWebアプリのURLをスマホのブラウザ（Safari / Chrome）で開きます。
   URL例: https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/

2. 【超おすすめ】スマホの「ホーム画面に追加」
   - iPhone (Safari): 画面下の共有ボタン（四角から矢印） ➔「ホーム画面に追加」
   - Android (Chrome): 右上のメニュー（3点リーダー） ➔「ホーム画面に追加」
   ➔ まるで専用のネイティブアプリのように、アイコンをタップするだけで起動できます！

3. 画面上のタブをタップして、各出張の最新価格や値下がり状況を確認できます。


================================================================================
3. 新しい出張・旅行の登録方法
================================================================================
画面上部のタブから「➕ 出張・旅行を登録」を選択します。

1. 宿泊日程【必須】:
   - 単一日（例: 2026-10-15）またはカンマ区切り（例: 10/15, 10/22, 11/05）
2. 行き先【必須】:
   - 駅名やランドマーク名（例: 東京駅、博多駅、幕張メッセ）
   ※緯度経度は不要です。自動で地図上の位置が測位されます。
3. 予約済み価格【任意】:
   - 既にキープしているホテルの金額（例: 12000）。未予約なら空欄。
4. こだわり条件【任意】:
   - 1泊上限予算（例: 15,000円）
   - 許容徒歩分数（例: 10分以内）
   - 喫煙/禁煙（禁煙 / 喫煙 / 指定なし）
   - 朝食（指定なし / 朝食あり）
   - レビュー評価（3.5以上 / 4.0以上 / 4.5以上）

➔「登録して結果を表示する 🚀」を押すと、即座に画面が切り替わり結果が表示されます！

4. 楽天＆じゃらん公式無料APIキーの取得手順
================================================================================
※APIキーが未設定の状態でも、本システムはリアルなデモデータで画面表示が可能です。
公式APIキーを設定すると、本物のリアルタイム空室データが自動巡回されます。
どちらも【完全無料・クレジットカード不要・数分】で取得できます。

--------------------------------------------------------------------------------
【楽天トラベル API（アプリID）の取得】
--------------------------------------------------------------------------------
1. Rakuten Developers（https://webservice.rakuten.co.jp/）にアクセスします。
2. お手持ちの楽天IDでログインします。
3. 画面右上の「アプリ新規作成」をクリックします。
4. 以下を入力して「規約に同意して新規作成」をクリックします：
   - アプリ名: 宿泊価格監視
   - アプリURL: あなたのGitHubリポジトリのURL（例: https://github.com/ユーザー名/リポジトリ名）
5. 画面に表示される【アプリID / デベロッパーID】（英数字の文字列）をコピーして控えます。

--------------------------------------------------------------------------------
【じゃらん API（リクルートAPIキー）の取得】
--------------------------------------------------------------------------------
1. リクルートWEBサービス（https://webservice.recruit.co.jp/）にアクセスします。
2. 「新規登録」をクリックし、メールアドレスを登録します。
3. 届いた確認メールのリンクを開き、利用規約に同意して登録を完了します。
4. 画面に表示される【APIキー】（英数字の文字列）をコピーして控えます。


================================================================================
5. GitHubリポジトリの設定（初期セットアップ）
================================================================================
1. GitHub Pagesの有効化（Web画面の公開）
   - GitHubのリポジトリページを開きます。
   - [Settings] ➔ [Pages] をクリックします。
   - [Build and deployment] の [Branch] で：
     - ブランチ: `main`
     - フォルダ: `/docs`
     を選択して [Save] をクリックします。
   - 数分後、上部にWebページの公開URLが表示されます！

2. APIキーの登録（GitHub Secrets）
   - [Settings] ➔ [Secrets and variables] ➔ [Actions] をクリックします。
   - [New repository secret] から以下の2つを登録します：
     - Name: `RAKUTEN_APP_ID` / Secret: 控えた楽天アプリID
     - Name: `JALAN_API_KEY` / Secret: 控えたじゃらんAPIキー

これでセットアップ完了です！毎朝8時（JST）に自動実行され、スマホ画面に反映されます。
いつでもGitHub Actionsの [Run workflow] ボタンから手動で即時実行することも可能です。
