================================================================================
【完全マニュアル】宿泊価格監視システム（スマホ対応 All-in-One Webアプリ版）
================================================================================

本システムは、出張や旅行の宿泊条件を登録しておくだけで、楽天トラベルとじゃらんの
公式空室検索APIを毎朝自動巡回し、最安プランや乗り換え推奨プランをスマホ画面で
直感的に確認できる自動監視システムです。

Googleスプレッドシートや別アプリへの移動は一切不要！
本Webアプリの画面1つだけで「登録」「検索」「確認」がすべて完結します。

1. このシステムでできること
================================================================================
(1) 予約済みホテルの乗り換えチェッカー
    - とりあえず仮予約（キープ）している総額（例: 24,000円）を登録しておくと、
      それより安いプランが出現した時に「🔥 価格改定検出！ 最大 -¥2,500 安い！」
      と視覚的に特大ハイライトされます。
    - キャンセル料無料の期間中に、より安くて良い宿に乗り換えることができます。

(2) 未予約時の「最安TOP 5」ランキング
    - まだ宿を予約していない出張は、条件（禁煙・朝食・徒歩・星評価）に合致する
      おすすめ宿を料金の安い順にベスト5をカード表示します。

(3) ワンタップで公式予約ページへ直行
    - 各ホテルカードの「楽天トラベルで詳細を確認」「じゃらんで詳細を確認」ボタンを押すだけで、
      そのまま公式のプラン予約ページへ一発でジャンプできます。

(4) 目的地の住所・店舗名ダイレクト入力
    - 小売店、呉服店、取引先の住所（例: 愛知県名古屋市中区栄3-16-1）をそのまま
      貼り付けるだけで、番地・街区レベルで自動測位して最寄りの宿を特定します。

(5) 毎朝8時（JST）の自動価格更新
    - GitHub Actionsが毎朝自動で最新の空室・価格をチェックし、Web画面を自動更新します。


================================================================================
2. 毎日の使い方（スマホで1タップ）
================================================================================
1. 発行されたWebアプリのURLをスマホのブラウザ（Safari / Chrome）で開きます。
   URL例: https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/

2. 【超おすすめ】スマホの「ホーム画面に追加」
   - iPhone (Safari): 画面下の共有ボタン（四角から矢印） ➔「ホーム画面に追加」
   - Android (Chrome): 右上のメニュー（3点リーダー） ➔「ホーム画面に追加」
   ➔ まるで専用のネイティブアプリのように、アイコンをタップするだけで起動できます！

3. 画面上のタブをタップして、各出張の最新価格や値下がり状況を確認できます。


================================================================================
3. 新しい出張・旅行の登録方法
================================================================================
画面上部のタブから「新規出張の登録」を選択します。

1. 管理名【必須】:
   - 出張や旅行の名称（例: 10月 東京出張、大阪展示会視察）
2. 目的地【必須】:
   - 住所直接入力、店舗名、最寄り駅、展示会場名など
   - サジェスト候補から選ぶか、住所をそのまま貼り付けて入力可能です。
3. チェックイン日【必須】:
   - カレンダーから宿泊日を選択
4. 宿泊数（泊数）【必須】:
   - 泊数を入力（例: 2泊）
5. 仮予約済みの総額【任意】:
   - 既にホテルを確保している場合に入力（全泊分の税込総額を入力します）
   - ※未予約の場合は空欄
6. こだわり条件:
   - 1泊上限予算: 1泊あたりの上限金額（例: 16,000円）
   - 許容徒歩分数: 基準地からの徒歩上限（5分〜20分）
   - 喫煙/禁煙、朝食の有無、レビュー評価（★4.0以上、指定なし等）、宿泊人数

➔「登録して価格監視を開始する」を押すと、即座に価格比較一覧が表示されます！


================================================================================
4. 「乗り換えチャンス！」と「最安TOP5」の見方
================================================================================
(1) 緑色のバナー「価格改定検出（乗り換えチャンス）」:
    - 仮予約済みの総額を下回るプランが見つかると、バナーが緑色に変化し
      「現在予約中の総額より ¥X 安価なプランが見つかりました」と表示されます。
    - 各ホテルカードに「現在予約より -¥X」の割引バッジが表示されます。

(2) 青色のバナー「未予約・最安プラン一覧」:
    - 仮予約金額を入力していない出張では、指定条件を満たす最安ホテル上位5件が
      ランキング形式で一覧表示されます。

(3) 灰色のバナー「予約状況: 確保済み」:
    - 現在の仮予約価格が、検索されたどのプランよりも安い場合に表示されます。
      現在の予約をそのままキープすることが推奨されます。

5. Web画面登録とGitHub Actions自動巡回の連携について
================================================================================
【重要: データの保存先と自動更新の仕組み】
- Web画面（スマホ）から登録した出張は、お使いのスマホの「ブラウザ内（localStorage）」
  に保存され、即座に画面上で比較・確認できます。
- GitHub Actionsによる毎朝8時の自動価格巡回は、リポジトリ内の「conditions.json」
  に記載された条件を読み込んで実行されます。
- そのため、PCやチーム全体で共有し、毎朝自動で最新価格を監視・更新したい案件は、
  リポジトリの `conditions.json` に出張情報を追記してコミットしてください。

6. 楽天＆じゃらん公式無料APIキーの取得手順
================================================================================
※APIキーが未設定の状態でも、本システムはリアルなデモデータで画面表示が可能です。
公式APIキーを設定すると、本物のリアルタイム空室データが自動巡回されます。
どちらも【完全無料・クレジットカード不要・数分】で取得できます。

--------------------------------------------------------------------------------
【楽天トラベル API（アプリID）の取得】
--------------------------------------------------------------------------------
1. Rakuten Developers（https://webservice.rakuten.co.jp/）にアクセスします。
2. お手持ちの楽天IDでログインします。
3. 画面右上の「アプリ新規作成」をクリックします。
4. 以下を入力して「規約に同意して新規作成」をクリックします：
   - アプリ名: 宿泊価格監視
   - アプリURL: あなたのGitHubリポジトリのURL（例: https://github.com/ユーザー名/リポジトリ名）
5. 画面に表示される【アプリID / デベロッパーID】（英数字の文字列）をコピーして控えます。

--------------------------------------------------------------------------------
【じゃらん API（リクルートAPIキー）の取得】
--------------------------------------------------------------------------------
1. リクルートWEBサービス（https://webservice.recruit.co.jp/）にアクセスします。
2. 「新規登録」をクリックし、メールアドレスを登録します。
3. 届いた確認メールのリンクを開き、利用規約に同意して登録を完了します。
4. 画面に表示される【APIキー】（英数字の文字列）をコピーして控えます。

7. GitHubリポジトリの設定（初期セットアップ）
================================================================================
1. GitHub Pagesの有効化（Web画面の公開）
   - GitHubのリポジトリページを開きます。
   - [Settings] ➔ [Pages] をクリックします。
   - [Build and deployment] の [Branch] で：
     - ブランチ: `main`
     - フォルダ: `/docs`
     を選択して [Save] をクリックします。
   - 数分後、上部にWebページの公開URLが表示されます！

2. APIキーの登録（GitHub Secrets）
   - [Settings] ➔ [Secrets and variables] ➔ [Actions] をクリックします。
   - [New repository secret] から以下の2つを登録します：
     - Name: `RAKUTEN_APP_ID` / Secret: 控えた楽天アプリID
     - Name: `JALAN_API_KEY` / Secret: 控えたじゃらんAPIキー

これでセットアップ完了です！毎朝8時（JST）に自動実行され、スマホ画面に反映されます。
いつでもGitHub Actionsの [Run workflow] ボタンから手動で即時実行することも可能です。

8. conditions.json の設定仕様と単位について
================================================================================
conditions.json で指定する各項目の単位・仕様は以下の通りです：

| 項目名 | 型 | 説明・単位 | 例 |
|---|---|---|---|
| id | 文字列 | 一意のID（まとめ打ち時は日付ごとに自動識別） | "trip-20261015-tokyo" |
| management_name | 文字列 | 管理名 | "10月 東京出張" |
| checkin_date | 文字列 | カンマ区切りでまとめ打ち可能 | "2026-10-15, 2026-10-22" |
| stay_nights | 整数 | 宿泊日数（1以上） | 2 |
| destination | 文字列 | 目的地（住所、駅名、店舗名） | "愛知県名古屋市中区栄3-16-1" |
| target_lat / target_lon | 数値/null | 緯度経度。nullの場合はdestinationから自動測位 | null |
| max_walk_minutes | 整数 | 基準地からの許容徒歩分数 | 10 |
| budget_max | 整数 | 【重要】「1泊あたり」の上限予算（円・税込） | 16000 |
| booked_price | 整数/null | 【重要】「全泊分の総額」（円・税込）。未予約はnull | 22000 |
| smoking | 文字列 | "禁煙" / "喫煙" / "指定なし" | "禁煙" |
| breakfast | 文字列 | "朝食あり" / "指定なし" | "指定なし" |
| min_review_rate | 数値 | レビュー下限（0.0で指定なし） | 3.8 |
| status | 文字列 | "監視中" で自動巡回対象（"終了" でスキップ） | "監視中" |

※ target_lat, target_lon を省略（または null）にしておくと、destination の変更に
  合わせて国土地理院・Nominatimから最新の座標が常に自動測位されます。
