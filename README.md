# 🏨 宿泊価格監視 Bot（All-in-One スマホWebアプリ版）

> 楽天トラベル ＆ じゃらん公式空室検索APIを活用した、最も見やすく使いやすいホテル価格自動監視システム。  
> スプレッドシートや別アプリへの移動は不要！スマホのWeb画面1つで「登録」「検索」「確認」が完結します。

---

## 🌟 主な特徴

1. **📱 スマホで見やすいカード型Webダッシュボード（GitHub Pages）**
   - ホテル外観写真、最安価格、徒歩分数、★レビュー評価、禁煙・朝食タグ付き。
   - 各ホテルの「楽天トラベルで詳細を確認」「じゃらんで詳細を確認」ボタンを押すだけで、**公式の予約ページへ直行**！
   - スマホのホーム画面に追加すれば、アプリ感覚でワンタップ起動。

2. **🔥 予約済みホテルの「乗り換えチェッカー」**
   - とりあえず確保している予約価格（全泊総額）を登録しておくと、**「現在の予約より -¥2,500 安い！」** と特大ハイライト。
   - 無料キャンセル期限までに、よりお得で良いホテルへスムーズに乗り換えられます。

3. **🏆 未予約時は「最安TOP 5」をランキング表示**
   - まだ予約していない出張は、条件に合致する上位5件のおすすめプランを料金順にスッキリ表示。

4. **📍 目的地の住所・店舗名ダイレクト入力**
   - 小売店、呉服店、取引先の住所（例: `愛知県名古屋市中区栄3-16-1`）をそのまま貼り付けるだけで、国土地理院APIにより番地・街区レベルで自動測位して周辺ホテルを特定。

5. **⚡ 日程の「まとめ打ち」対応**
   - カレンダー指定はもちろん、`conditions.json` では「10/15, 10/22」などカンマ区切りで複数日分を一括監視。

6. **🤖 毎朝8時（JST）の完全自動更新**
   - GitHub Actionsにより、毎朝自動で最新の空室・価格をチェックしWeb画面を自動更新（完全無料・サーバーレス）。

## 🚀 クイックスタート

### 1. Webアプリの公開（GitHub Pages）
1. GitHubリポジトリの [Settings] ➔ [Pages] を開く。
2. [Branch] で `main`、フォルダで `/docs` を選択して [Save]。
3. 発行されたURLをスマホで開き、**「ホーム画面に追加」** してください！

### 2. 楽天＆じゃらん公式無料APIキーの登録（GitHub Secrets）
1. [Settings] ➔ [Secrets and variables] ➔ [Actions] を開く。
2. [New repository secret] から以下を登録：
   - `RAKUTEN_APP_ID`: 楽天Developersで発行したアプリID（無料）
   - `JALAN_API_KEY`: リクルートWEBサービスで発行したAPIキー（無料）
※キー未設定の場合でも、リアルなデモデータでWeb画面の動作確認が可能です。
